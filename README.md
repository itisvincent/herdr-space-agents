# Space agents (Herdr mod)

Show only the **current space’s** agents in the sidebar (toggle back to all).

```text
Tell your agent:
Read ~/.config/herdr-app/AGENTS.md, then add this mod: https://github.com/itisvincent/herdr-space-agents
```

Point your layout’s agents block at `"mod": "space-agents"` (clone a layout first).

See [RECIPE.md](RECIPE.md).
